Install

安装说明

  1. 打开 DMG
    双击下载好的 FLOW.dmg。
  2. 拖入「应用程序」
    把 FLOW 图标拖到 Applications 文件夹。
  3. 首次打开
    macOS 会提示「无法验证开发者」——右键（或按住 Control 点击）FLOW → 选「打开」→ 弹窗里再点「打开」。或到「系统设置 → 隐私与安全性 → 仍要打开」。

之后即可正常双击启动。FLOW 是本地运行的独立构建，暂未经过 Apple 公证，所以首次打开需要手动放行一次。
